# Soporte de Anatomify

Anatomify es una aplicación gamificada para estudiar anatomía, dirigida a estudiantes de medicina y profesionales de la salud, con módulos interactivos sobre todos los sistemas del cuerpo humano.

## Preguntas frecuentes

## ¿Cómo inicio sesión?

Puedes iniciar sesión con tu Apple ID o correo electrónico. Tu progreso se sincroniza entre dispositivos cuando utilizas la misma cuenta.

## ¿Cómo me suscribo a Anatomify+?

Toca cualquier módulo bloqueado para abrir la pantalla de suscripción con 3 planes (mensual, 6 meses y anual). El plan de 6 meses incluye 3 días de prueba gratuita y el plan anual incluye 7 días de prueba gratuita.

## ¿Cómo cancelo mi suscripción?

Ve a Ajustes → Apple ID → Suscripciones → Anatomify+ → Cancelar suscripción. Mantendrás el acceso hasta el final del período de facturación actual.

## ¿Cómo restauro mis compras en un dispositivo nuevo?

Abre la pantalla de suscripción en la aplicación y toca “Restaurar compras”. Asegúrate de haber iniciado sesión con el mismo Apple ID utilizado para la compra original.

## ¿Qué incluye la versión gratuita?

El subsistema Cráneo (sistema esquelético), el módulo Cara anterior (sistema muscular) y el subsistema General (sistema nervioso). Todo el contenido restante requiere Anatomify+.

## ¿Cómo elimino mi cuenta?

Ve a Perfil → Configuración → Eliminar cuenta dentro de la aplicación. Esto eliminará tus datos permanentemente.
