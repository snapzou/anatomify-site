# Suporte do Anatomify

O Anatomify é um aplicativo gamificado para o estudo de anatomia, desenvolvido para estudantes de medicina e profissionais da saúde, com módulos interativos sobre todos os sistemas do corpo humano.

## Perguntas frequentes

## Como faço para entrar?

Você pode entrar com seu ID Apple ou e-mail. Seu progresso é sincronizado entre dispositivos quando você usa a mesma conta.

## Como faço para assinar o Anatomify+?

Toque em qualquer módulo bloqueado para abrir a tela de assinatura com 3 planos (mensal, semestral e anual). O plano semestral inclui 3 dias de teste grátis, e o plano anual inclui 7 dias de teste grátis.

## Como faço para cancelar minha assinatura?

Acesse Ajustes → ID Apple → Assinaturas → Anatomify+ → Cancelar assinatura. Você continuará com acesso até o fim do período de cobrança atual.

## Como restauro minhas compras em um novo dispositivo?

Abra a tela de assinatura no aplicativo e toque em “Restaurar compras”. Verifique se você está conectado com o mesmo ID Apple usado na compra original.

## O que está incluído na versão gratuita?

O subsistema Crânio (sistema esquelético), o módulo Face Anterior (sistema muscular) e o subsistema Geral (sistema nervoso). Todo o restante do conteúdo requer o Anatomify+.

## Como excluo minha conta?

Acesse Perfil → Configurações → Excluir conta dentro do aplicativo. Isso removerá seus dados permanentemente.
